# US-012 — Receive new urgent tasks in real time

## Statement
**As a** P-02 (general technician), **I want to** receive a push notification when an urgent task is assigned to me during the day, **so that** I can reroute without phone calls from the manager.

## Acceptance criteria
- Given the app is running and the device has connectivity, when an urgent task is assigned, then I receive a push notification within 60 seconds.
- Given I tap the notification, when the app opens, then the new task is highlighted in the list.
