# T-002 — Today screen with building grouping

## Status
planned

## Stories
- US-003

## Acceptance
- Given the user has 5 tasks across 3 buildings today, when Today renders, then 3 building groups appear with the correct tasks under each.
- Given the user has no tasks today, when Today renders, then an empty-state message is shown with clear next-step guidance.
- Given the backend is unreachable on first ever sign-in, when Today loads, then a retry-able error appears.
