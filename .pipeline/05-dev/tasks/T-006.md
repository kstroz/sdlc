# T-006 — Block task with preset reason

## Status
planned

## Stories
- US-008

## Acceptance
- Given the user taps "Cannot complete" and selects "needs parts", when they confirm, then the Task row updates to status=blocked with blockReason="needs_parts" and an OutboxAction is enqueued in the same transaction.
- Given the user wants to add a free-text note, when they enter one and confirm, then the note is saved on the Task row.
- Given the user changes mind, when they back out before confirming, then no state changes are persisted.
