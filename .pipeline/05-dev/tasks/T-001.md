# T-001 — Authentication and session persistence

## Status
planned

## Stories
- US-001
- US-002

## Acceptance
- Given valid credentials, when the user submits the sign-in form, then the backend returns 200 with a session token and the app routes to Today.
- Given invalid credentials, when the user submits, then the app shows a generic invalid-credentials error and stays on the sign-in screen.
- Given a stored session within its expiry window, when the user opens the app, then the app routes directly to Today without prompting for credentials.

## Test plan

- Unit: `src/use-cases/restoreSession.test.ts` — covers valid session, expired session, missing session
