# T-010 — Backend ePrzeglądy forwarding worker

## Status
done

## Stories
- US-013

## Acceptance
- Given a task completion is persisted on the backend, when the forwarding worker picks it up, then ePrzeglądy receives the completion record within 1 hour.
- Given ePrzeglądy returns 5xx, when the worker retries with exponential backoff up to 3 hours, then the completion is delivered without manual intervention.
- Given ePrzeglądy is unavailable for 24 hours, when the queue length exceeds 1000, then a monitoring alert fires; the technician's app remains unaffected.
