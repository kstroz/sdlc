# T-007 — Outbox sync worker with retry and FIFO ordering

## Status
planned

## Stories
- US-010

## Acceptance
- Given 3 queued OutboxActions, when connectivity is detected, then the worker processes them in FIFO order and removes succeeded actions from the queue.
- Given an action fails with a transient error, when the next sync runs, then the action is retried using exponential backoff (2, 4, 8, 16, 32 seconds).
- Given an action has failed 5 times, when the next sync runs, then it is marked permanently failed and the failure count is surfaced in the UI banner.
- Given the app is killed mid-sync, when it relaunches, then in_flight actions are reset to pending and replay continues.
