# T-009 — Push notifications for urgent tasks

## Status
done

## Stories
- US-012

## Acceptance
- Given the app is in background and a new urgent task is assigned server-side, when the push arrives, then the OS surfaces a notification within 60 seconds.
- Given the user taps the notification, when the app foregrounds (from background or cold start), then it routes to the task detail for the new task.
- Given push permission is denied, when an urgent task is assigned, then a banner highlights it on next foreground (in-app fallback).
