# T-005 — Mark done with photo, offline-capable

## Status
done

## Stories
- US-006
- US-007
- US-009

## Acceptance
- Given the device is offline and the user taps Mark done, when the completion sheet confirms with one photo attached, then within the same WatermelonDB transaction the Task row updates to status=done, a Photo row is created with localPath set, and an OutboxAction with idempotency key is enqueued.
- Given camera permission is denied, when the user attempts to take a photo, then a clear path to Settings is offered.
- Given the task is already done, when the user opens it, then the Mark done button is replaced by the completion summary (timestamp, photo thumbnails).
