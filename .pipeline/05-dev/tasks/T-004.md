# T-004 — Local offline store and cache layer

## Status
planned

## Stories
- US-009

## Acceptance
- Given the device is offline and the cache has been populated by a prior session, when the user opens Today, then the list renders within 1 second using local data.
- Given the device is offline, when the user opens any in-scope screen, then no field shows "Loading..." indefinitely; either data is present or a clear empty state is shown.
- Given a server pull happens after schema migration, when the cache is updated, then existing local rows are preserved.
