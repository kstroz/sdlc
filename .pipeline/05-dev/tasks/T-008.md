# T-008 — Wifi-only media policy

## Status
planned

## Stories
- US-011

## Acceptance
- Given the wifi-only setting is enabled and the device is on cellular, when the sync worker runs, then non-media actions sync but photo upload OutboxActions are skipped and a banner explains why.
- Given the device joins wifi while photos are queued, when sync runs, then queued photos are uploaded.
- Given the user toggles the setting off, when sync runs next, then queued photos are uploaded regardless of network type.

## Test plan
- Unit: `src/domain/sync/mediaPolicy.test.ts` — covers policy decision matrix (action type x network type x setting)
- Unit: `src/use-cases/processOutbox.test.ts` — extended cases for wifi-only skip
- Unit: `src/platform/network/networkType.test.ts` — covers cellular vs wifi detection
